# 🎓 StudentHub – Smart Student Task Management System

### Plan Smarter. Study Better. Achieve More.

StudentHub is a modern and interactive student productivity web application designed to help college students organize their academic responsibilities in one place.

It allows students to manage assignments, projects, examinations, study schedules, and personal activities while tracking their productivity and academic progress.

## ✨ Features

### 🔐 Authentication System
- Student registration and login.
- Form validation.
- Password visibility toggle.
- Remember Me functionality.
- Forgot Password flow.
- Personalized student profiles.
- Logout functionality.

### 📊 Dashboard
- Personalized welcome message.
- Total, pending, completed, and overdue task statistics.
- Overall task completion progress.
- Upcoming deadlines.
- Daily task overview.
- Productivity charts.

### 📝 Task Management
- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Mark tasks as completed.
- Set task priorities (High, Medium, Low).
- Manage task deadlines.
- Search and filter tasks.
- Track task status.

### 📅 Interactive Calendar
- Monthly and weekly calendar views.
- View tasks according to deadlines.
- Highlight upcoming and overdue tasks.
- Add tasks directly from the calendar.

### 📚 Study Planner
- Create study schedules.
- Organize sessions by subject.
- Track planned and completed study sessions.
- Manage daily study activities.

### ⏱️ Focus Mode
- Pomodoro timer.
- 25-minute focus sessions.
- 5-minute short breaks.
- 15-minute long breaks.
- Start, pause, and reset controls.

### 📈 Productivity Analytics
- Weekly productivity charts.
- Monthly task completion.
- Subject-wise task distribution.
- Completed versus pending tasks.
- Study hours tracking.
- Productivity progress.

### ⚙️ Settings
- Edit student profile.
- Update personal information.
- Light and dark themes.
- Manage application preferences.
- Reset application data.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd StudentHub
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 💡 Project Objective

The main objective of StudentHub is to make academic management easier and more organized for college students.

Instead of managing assignments, examinations, and study schedules separately, students can access everything through one centralized platform.

## 🔒 Security Note

This version is a front-end prototype. Authentication and local storage are intended for demonstration purposes and are not a replacement for secure backend authentication. Production deployment should use secure password hashing, server-side authentication, and a protected database.
